# 素材与组件来源

## GooseHyperGlass

- 项目：Minecraftgoose/GooseHyperGlassCDN
- 版本：2.5.1
- 文件：`goose-hyper-glass/liquid-glass.js`
- 许可证：Apache-2.0
- 上游及第三方声明：`goose-hyper-glass/NOTICE.txt`

页面使用真实的 `<liquid-glass>` 自定义元素，并对纵向导航、玻璃面板和搜索弹窗进行了适配。
